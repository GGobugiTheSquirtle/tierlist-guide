카드 디자인 변경 사항

  • 배경 단색 → subtle gradient (top-to-bottom, 2-stop)
  • 테두리 flat → 1px border + top-edge highlight line (::before)
  • 하이라이트 border-color만 → glow shadow + gradient overlay 추가
  • 아이콘 flat → box-shadow 추가 (깊이감), border-radius 6→8px
  • 메타 행 속성+무기+스타일 뱃지를 한 행으로 통합 (공간 절약)
  • L/S 아이콘 위 오버레이 → 텍스트+배경으로 더 명확하게
  • 호버 translateY(-2px) → translateY(-3px) + 더 강한 glow shadow
  • 삭제 버튼 위치 유지, 사이즈 약간 축소 (18→16px)
  • 카드폭 88px → 92px (정보 가독성 개선)

이 섹션이 괜찮으면 다음으로 티어 행 + 헤더 + 캡처 출력 디자인을 보여드리겠습니다.
